# GitHub Inspiration for Portifolio

This portfolio was built using React and CSS. Most of the design was inspired by GitHub, but I added my own personal touches to make it unique.

## Installation

```bash
npm install
```

## Run

```javascript
npm start
```

## Build

```javascript
npm run build
```

## Deploy

```javascript
npm run deploy
```
